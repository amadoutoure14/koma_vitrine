## 🛠 Développement Local

1. Cloner le repository
```bash
git clone https://github.com/amadoutoure14/koma_vitrine.git
cd koma_vitrine
```

2. Ouvrir avec un serveur local (ex: Live Server)
```bash
# Avec Python
python -m http.server 8000

# Avec Node.js
npx serve
```

3. Ouvrir dans le navigateur : `http://localhost:8000`

## 📝 Modifications

Pour modifier le contenu :
- **Textes** : Éditer `index.html`
- **Styles** : Éditer `styles.css`
- **Comportements** : Éditer `script.js`
- **Images** : Remplacer dans le dossier `assets/`
